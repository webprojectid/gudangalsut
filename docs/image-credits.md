# Foto produk inventaris

184 kelompok foto dipakai bersama oleh 906 kode barang. File WebP disimpan di `assets/products/catalog/`, bukan di Supabase. Foto yang sudah ada sebelum impor lanjutan dipertahankan.

Foto hasil pencarian adalah referensi model atau jenis produk, bukan dokumentasi unit fisik kampus. Nama yang tidak menetapkan model lengkap memakai referensi jenis. BAFO B30030 dan ATEN V0202 memakai referensi keluarga produk karena kecocokan model sumber belum dapat dipastikan; V-GEN Platinum memakai referensi keluarga karena kapasitas dan jenis modul tidak tercantum. Sumber foto tersedia di panel detail dan tabel berikut; tidak ada klaim bahwa seluruh foto berlisensi terbuka.

Nama “keystone lock” sementara ditafsirkan sebagai kunci pengaman laptop dan diberi penanda `requiresConfirmation`; pertanyaan konfirmasi identitas telah disampaikan kepada pengguna. Foto obeng merupakan cutout turunan sumber publik yang latarnya dibersihkan dengan imagegen bawaan; prompt dan file final dicatat di `photo-import-notes.md`.

Untuk model baru, tambahkan foto lokal, satu record `models` dan alias nama yang dinormalisasi di `byName`. Kode baru dengan alias nama yang sama otomatis memakai foto tersebut. `byCode` memeriksa nama agar kode yang dipakai ulang tidak menunjuk foto model lama. Format lama `{ "Kode-1": "assets/photos/asset.webp" }` tetap didukung sebagai override foto aset.

Foto kategori cadangan `monitor-photo.png` berasal dari [Dell Computer Monitor.png, IT Photography](https://commons.wikimedia.org/wiki/File:Dell_Computer_Monitor.png), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
